## Qué hace IkerCare

IkerCare es una herramienta de organización personal y familiar de información de salud. Permite registrar tratamientos, medicamentos, alimentación, eliminación, signos vitales, eventos, equipo tratante, hospitalizaciones, documentos clínicos y resúmenes compartibles. No reemplaza atención médica, indicaciones del equipo tratante ni la ficha clínica oficial de un prestador.

## Categorías de datos

Según las funciones utilizadas, se pueden tratar datos de cuenta/contacto; datos identificatorios del paciente; fotografía; datos de salud; medicamentos; síntomas/eventos; alimentación y eliminación; documentos e imágenes clínicas; profesionales tratantes; hospitalizaciones; datos de colaboración y auditoría; y metadatos técnicos estrictamente necesarios para seguridad/operación.

## Finalidades

- prestar las funciones solicitadas por el usuario;
- sincronizar información entre cuidadores autorizados;
- generar resúmenes solicitados;
- compartir temporalmente información cuando un usuario autorizado crea un enlace/QR;
- seguridad, prevención de abuso, auditoría y soporte;
- cumplir obligaciones legales aplicables.

No usar datos de salud para publicidad conductual ni venderlos a data brokers.

## Menores de edad

Quien incorpore datos de un menor debe declarar que cuenta con la autorización, representación o calidad suficiente para administrarlos. Los mecanismos definitivos de consentimiento/representación deben ser revisados legalmente para el mercado donde se ofrezca la aplicación.
